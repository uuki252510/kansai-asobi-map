# 実装前調査と変更方針

## 調査時点

- Next.js 16.2.4 / React 19 / TypeScript / Tailwind CSS 4
- App Router。公開一覧 `/places`、詳細 `/places/[id]`、管理 `/admin`
- Supabase `places` 741件、`reviews` 0件
- 公開ユーザー認証なし。管理画面はCookieと環境変数トークン
- お気に入りは端末内保存、地図は外部Google Mapsリンク中心
- デプロイ設定はVercelを想定した構成
- 既存ビルドは成功。`middleware.ts` の非推奨警告があったためNext.js 16の `proxy.ts` に移行

## 非破壊方針

- 既存 `places`、既存レコード、`/places` URLを削除・変更しない
- 新しいDB要件は追加型migrationのみ
- 新カラム未適用時も公開画面は正規化して表示継続
- 不明な営業時間、料金、設備、混雑は推測しない
- 新しい匿名書き込みはサーバーAPIに集約し、DBの匿名直接書き込みは許可しない
